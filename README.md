# Aegis

Transparent IPv4 HTTP reverse path for isolated Attack-Defense environments. Aegis uses mitmproxy native `transparent` mode, `SO_ORIGINAL_DST`, and only its own `inet aegis` nftables table. It never terminates TLS or rewrites application code.

## Status

- **Network path:** real Docker/network-namespace integration passes GET, JSON POST, Host/query/body preservation, keep-alive, Flask/FastAPI/NGINX, dynamic listener :31337, SSH/HTTPS bypass, telemetry/original-destination check, emergency fail-open, and watchdog response to a stopped proxy event loop.
- **Model benchmark:** complete for exactly the three requested pinned models. The primary table and per-model confusion matrices are in `benchmarks/results.md`; raw requests are not recorded. No blocking model is selected. Default detector remains `AllowAllDetector`; Cyber-Jev can be enabled only as bounded asynchronous observe-only inference.
- See `benchmarks/network_results.md` for measured results and test scope.

## Requirements

Ubuntu 22.04/24.04, Python 3.11+, systemd, nftables, iproute2 (`ss`), root for installation and firewall operations. On Ubuntu 22.04, `install.sh` installs the official `python3.11` and venv packages when the system Python is older; Ubuntu 24.04 uses its Python 3.12. `run.sh` creates `/opt/aegis/venv` and downloads Python dependencies with pip on first run; apt installs `nftables`, `iproute2`, and `python3-venv`.

```sh
sudo ./run.sh
sudo systemctl status aegis-proxy aegis-discovery aegis-watchdog.timer
sudo ./stop.sh
sudo ./emergency-stop.sh
```

Review `config.yaml` before first run. The installer copies it to `/etc/aegis/config.yaml`. `start.sh` starts installed units; `run.sh` installs when the virtualenv is absent. Proxy port is 18080. If occupied, change both the config and `systemd/aegis-proxy.service` before installing.

## Observe-only model activation

The default `config.yaml` is `detector.mode: allow-all`. Run `sudo ./run.sh` once to install/start Aegis; then edit `/etc/aegis/config.yaml` to enable shadow scoring with the Cyber-Jev candidate and run `sudo ./run.sh` again. Re-running the installer preserves an existing config:

```yaml
detector:
  mode: observe-only
  model: sdmlai/cyber-jev
  model_path: /opt/aegis/models/weights/sdmlai--cyber-jev/3fea0b1ec86ac3efd9d1352d5f1e4008cc0c17b7
  threshold: 0.962627218983115
  max_pending: 64
```

`run.sh` downloads only that pinned release archive when the configured weight file is missing, verifies its SHA-256 sidecar, then starts the services. Scores are written to telemetry asynchronously; a full queue drops observation records rather than delaying or blocking HTTP traffic. This candidate is not a safe block-mode winner. Cyber-Jev is CC-BY-NC-4.0 and must not be used commercially.

## Firewall and routing behavior

- Only IPv4 TCP listeners that answer idempotent `HEAD /` are selected. Probes use `Host: aegis-probe.invalid`, `Connection: close`, and a short timeout. Ports in `excluded_ports` and the proxy port are never redirected.
- Listener enumeration runs each 10 seconds (`ss -4`). Docker published IPv4 TCP ports can be discovered from local `docker ps` and HTTP-probed; turn this off for a remote or untrusted Docker context.
- The nftables PREROUTING nat chain redirects matching TCP destination ports. It is installed at `dstnat - 5`, before Docker DNAT. The proxy opens the upstream connection to the original destination; outgoing connections do not traverse PREROUTING, so there is no proxy loop. No Docker rules or other firewall tables are edited.
- PREROUTING does not intercept requests generated by this host (`curl localhost`, loopback, or local OUTPUT). Use a remote client. IPv6 is not handled in this version.
- HTTPS and SSH are excluded. Unknown TCP is selected only if it answers the safe HTTP HEAD probe. There is no TLS MITM or block mode; optional model inference is observe-only.
- An independent systemd timer checks a proxy event-loop heartbeat. If the process dies or stalls, the watchdog removes only `table inet aegis`; systemd restarts the proxy. Existing conntrack NAT flows may fail until clients reconnect; new requests bypass directly to the backend.
- JSONL telemetry lives under `/run/aegis/telemetry.jsonl`. It stores method, Host header, path without query, original destination, detector label/score and latency. It does not store bodies or arbitrary headers.

## Lab and verification

The lab uses a dedicated Docker bridge and a separate client. Services share a network namespace so `ss` can discover their listeners. It includes Flask :5000, FastAPI :8000, NGINX :8080, late-starting HTTP :31337, SSH :2222, and TLS :8443. The lab does not use host networking for traffic and does not touch host nftables. Compose builds use host networking only for package downloads.

```sh
./tests/smoke.sh
./tests/integration.sh
./tests/docker_dnat.sh
./tests/observe.sh
```

The network integration script starts and removes only its Compose project. It runs 1,000 direct and transparent requests at concurrency 50, validates nftables counters and telemetry, and tests direct access after emergency stop and a SIGSTOP-induced proxy hang. `./tests/observe.sh` separately sends real intercepted requests through Cyber-Jev in a bounded background observer; routing is never gated on its result.

## Offline model benchmark

Run `./benchmarks/run.sh` to fetch pinned datasets and weights and reproduce the CPU benchmark; after caching, `./benchmarks/run.sh --offline` disables Docker networking. Results from the completed isolated, one-CPU run:

| Model | Size MB | FPR | Recall | F1 | p95 ms | RAM MB |
|---|---:|---:|---:|---:|---:|---:|
| Fizcko/argus_sentinel | 5.23 | 0.004 | 0.048 | 0.092 | 0.378 | 86.68 |
| khasinski/ai-bouncer | 34.37 | 0.571 | 0.977 | 0.767 | 0.668 | 125.90 |
| sdmlai/cyber-jev | 23.73 | 0.013 | 0.919 | 0.951 | 38.390 | 177.52 |

Metrics use 3,200 held-out MicroData test examples (1,600/class), with a separate 800-example validation split; 4,000 CSIC2010 examples and 250 curated benign requests are reported separately. CSIC is training-data contaminated for AiBouncer and Cyber-Jev and is not used for selection. MicroData excludes known overlapping source families; residual synthetic-template leakage is possible. Fitted thresholds use validation only. AiBouncer is evaluated at its native categorical label, not a fabricated probability.

No model is a safe blocking winner: Argus recall is only 4.8%; AiBouncer false-positive rate is 57.1%; Cyber-Jev has 1.25% held-out FPR, 38.39 ms p95, and 29.69 req/s on one CPU. Cyber-Jev produced no false positives on 250 curated benign requests, but 20 false positives among 1,600 held-out benign requests. It is exposed only as a shadow observer for controlled testing; the shipped default is allow-all. Cyber-Jev weights carry CC-BY-NC-4.0 restrictions. No automatic blocking is enabled.

## Repository map

- `aegis/`: discovery, nftables controller, mitmproxy addon, detector interface and watchdog.
- `systemd/`: proxy, discovery and independent watchdog timer.
- `lab/`, `tests/`: isolated HTTP services and real integration checks.
- `benchmarks/`: pinned offline datasets, independent model adapters, reproducible runner, and `results.md`.
- `aegis/model_backends.py`: model-specific backends; `aegis/detector.py` wraps them in a bounded observe-only queue.
